# Прогноз стоимости аренды квартиры в Москве

Выпускная квалификационная работа по курсу «Инженер данных (продвинутый)», ЦДО МГТУ им. Н.Э. Баумана.

Система собирает объявления о долгосрочной аренде, хранит их в слоях данных и PostgreSQL, контролирует
качество данных и по параметрам квартиры определяет цену аренды в месяц и ценовой класс.

## Быстрый запуск приложения

Нужны Windows, Python 3.12 и окружение `venv` (см. «Установка»).

1. Дважды щёлкните файл «Запустить приложение.bat».
2. В браузере откроется страница http://localhost:8501.
3. Заполните параметры квартиры и нажмите «Рассчитать цену».

Приложение работает без базы данных: ему нужны файлы модели, золотой слой и справочники.

## Установка

```
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для конвейера нужен PostgreSQL 17 и файл `.env` в папке проекта:

```
PGHOST=127.0.0.1
PGPORT=5432
PGDATABASE=rent
PGUSER=postgres
PGPASSWORD=пароль
PII_KEY=секретный ключ псевдонимизации
BACKUP_COPY_DIR=необязательная папка второй копии на другом диске
```

Файл `.env` в репозиторий не загружается. Ключ `PII_KEY` нужно хранить: без него новые сборы не сопоставятся со старыми.

## Конвейер данных

Двойной щелчок по файлу «Запустить конвейер.bat» (около полутора часов, нужно подтверждение). Этапы:

| Этап | Программа | Результат |
|---|---|---|
| Резервная копия | `src/backup.py` | `backups/<дата>/` |
| Сбор, удаление персональных данных | `src/collect_yandex.py`, `src/security.py` | бронзовый слой `data/bronze/` |
| Контроль качества | `src/quality.py` | таблица `quality_checks` |
| Загрузка | `src/lake.py` | серебряный слой: таблицы базы, `data/silver/` |
| Справочник станций | `src/build_metro.py` | `data/reference/metro_stations.csv` |
| Подготовка признаков и классов | `src/preprocess.py` | золотой слой: `offers_model`, `data/gold/` |
| Обучение и проверка качества модели | `src/train.py` | `models/`, `reports/metrics.json`, `model_runs` |

Журналы: `logs/pipeline.log`, таблица `pipeline_runs`, журнал прогнозов `logs/predictions.jsonl`.

Запуск по расписанию сейчас не включён. Его можно настроить в Планировщике Windows, указав полный путь к папке проекта:

```
schtasks /Create /SC WEEKLY /D SUN /ST 03:00 /TN "VKR rent pipeline" /TR "\"<папка>\venv\Scripts\python.exe\" \"<папка>\src\pipeline.py\" --yes"
```

Резервная копия и проверка восстановления: `venv\Scripts\python.exe src\backup.py --check`.
Восстановление базы: `pg_restore --clean --if-exists --no-owner --dbname=rent backups\<дата>\rent.dump`.

Автоматические проверки: `venv\Scripts\python.exe -m pytest tests`.

## Структура проекта

```
app.py            приложение (Streamlit)
src/              классы конвейера, модели и мониторинга
sql/schema.sql    описание таблиц базы данных и роли только для чтения
data/silver/      серебряный слой (бронзовый слой хранится только локально)
data/gold/        золотой слой: признаки и целевые переменные
data/reference/   станции метро, границы округов (© участники OpenStreetMap, ODbL)
models/           модель, контрольная модель и их описание
notebooks/        блокноты Jupyter с кодом и результатами
reports/          метрики, графики и журналы проверок
tests/            автоматические проверки
```

## Персональные данные

В бронзовый слой попадает только белый список полей. Имена, фото, телефоны, описания и ссылки на объявления
удаляются при сборе. Адрес и номер объявления заменяются псевдонимом HMAC-SHA256, координаты округляются до 3 знаков.

## Результат

Лучшая модель по перекрёстной проверке: градиентный бустинг. На тестовой выборке из домов, которых модель не видела:
средняя ошибка 17 353 руб. (14,7 процента от цены), R² = 0,805, верный ценовой класс в 70,8 процента случаев.
